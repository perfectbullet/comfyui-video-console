# ComfyUI 视频控制台 · 部署说明

> 前端提供 ｜ 2026-09-14 ｜ 项目 `comfyui-video-console`

我提供两样东西：**一个 `dist` 目录**（纯静态页面，164 KB）+ **下面这份 Nginx 配置**。

服务器上**不装 Node / Docker / PM2，不跑任何程序**，只需要 Nginx。页面走 HTTPS，后端通过同源反代访问。

---

## 一、文件放哪

把 `dist` 里的内容放进下面这个目录（直接覆盖，目录已存在）：

```bash
cp -r <dist 产物>/. /data/aigc/comfyui-h3/comfyui-video-console/
```

放完后目录里只应有 `index.html` 和 `assets/`（共 3 个文件）。以后发新版用新内容替换即可。

---

## 二、Nginx 配置

存成 `/etc/nginx/conf.d/comfyui-console.conf`，把 `<域名>`、证书路径改成实际的：

```nginx
server {
    listen 80;
    server_name <域名>;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    http2 on;                                   # nginx < 1.25.1 改成 listen 443 ssl http2;
    server_name <域名>;
    ssl_certificate     /etc/nginx/ssl/<域名>.crt;
    ssl_certificate_key /etc/nginx/ssl/<域名>.key;

    root  /data/aigc/comfyui-h3/comfyui-video-console;
    index index.html;
    client_max_body_size 200m;                  # 不设的话上传图片报 413
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;

    location / { try_files $uri $uri/ /index.html; }

    location /assets/ {                         # 文件名带哈希，可长缓存
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }
    location = /index.html {                    # 入口不缓存，否则发版后用户还在跑旧版
        add_header Cache-Control "no-store";
    }

    # ↓ 后端同源反代（末尾的 "/" 不能漏，漏了 404）
    location /archiver/ {
        proxy_pass http://192.168.8.231:8610/;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 200m;
        proxy_read_timeout 600s;
        proxy_buffering off;
    }

    location /comfyui/ {
        # ★ :8188 本身没有任何账号密码。外网也能访问 → 这两行不能省
        #   用密码认证，不要用 IP 白名单（外网用户 IP 不固定）
        auth_basic           "ComfyUI Console";
        auth_basic_user_file /etc/nginx/.htpasswd;

        proxy_pass http://192.168.8.231:8188/;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade    $http_upgrade;   # ComfyUI 的 WebSocket
        proxy_set_header Connection "upgrade";

        client_max_body_size 200m;
        proxy_read_timeout 1800s;   # 生成耗时长，默认 60s 会 504
        proxy_buffering off;        # 视频拖进度条需要
    }
}
```

```bash
sudo htpasswd -c /etc/nginx/.htpasswd <用户名>    # 建访问密码；以后加用户去掉 -c
sudo nginx -t && sudo nginx -s reload
```

页面是 HTTPS，直连 HTTP 后端会被浏览器按「混合内容」拦掉，所以两段反代不能省。

> 反代目标 `192.168.8.231:8610` / `:8188` 要能从这台 Nginx 访问；不通的话反代会报 `502`。
